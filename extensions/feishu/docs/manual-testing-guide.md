# 飞书新功能手动测试指南

## 🎯 新增功能概览

本次迁移新增了 **消息转换器系统** 和 **流式卡片增强**，主要改进了飞书消息的解析能力。

---

## 📋 新增功能列表

### 1. 消息转换器系统（20+ 种消息类型）

#### 之前的行为

- 只能解析基础消息类型（text, image, file）
- 富文本消息显示为简单文本
- 交互卡片显示为 `[Interactive Card]`
- 合并转发显示为 `[Merged Forward]`

#### 现在的行为

- ✅ 支持 20+ 种消息类型
- ✅ 富文本完整 Markdown 转换
- ✅ 交互卡片解析 70+ 元素类型
- ✅ 合并转发异步递归解析

### 2. 流式卡片增强

#### 之前的行为

- 基础流式卡片支持
- 固定节流参数

#### 现在的行为

- ✅ 可配置节流间隔
- ✅ 推理过程展示
- ✅ 异步图片上传（三层缓存）
- ✅ 消息可用性检测

## 🧪 手动测试步骤

### 准备工作

1. **确认服务运行**

   ```bash
   # 查看服务状态
   openclaw status

   # 如果未运行，启动服务
   openclaw start
   ```

2. **查看日志**

   ```bash
   # 实时查看日志
   openclaw logs -f

   # 或者在另一个终端窗口
   tail -f ~/.openclaw/logs/openclaw.log
   ```

3. **确认新转换器已启用**
   在日志中应该看到：
   ```
   feishu[main]: using new converter system
   ```

## 测试用例

### 测试 1：文本消息（基础功能）

**目的**：验证基础文本消息解析

**步骤**：

1. 在飞书中给机器人发送文本消息：`你好，测试文本消息`
2. 查看日志

**预期结果**：

```
feishu[main]: using new converter system
feishu[main]: new converter parsed content: 你好，测试文本消息
```

**验证点**：

- ✅ 日志显示 "using new converter system"
- ✅ 机器人正常回复

---

### 测试 2：富文本消息（Post）

**目的**：验证富文本 Markdown 转换

**步骤**：

1. 在飞书中创建富文本消息（点击输入框的 "富文本" 按钮）
2. 输入以下内容：

   ```
   标题：测试富文本

   这是一段**粗体**文字
   这是一段*斜体*文字
   这是一段~~删除线~~文字

   - 列表项 1
   - 列表项 2
   ```

3. 发送给机器人

**预期结果**：

- 日志显示解析后的 Markdown 格式
- 机器人能理解富文本内容

**验证点**：

- ✅ 标题被正确解析
- ✅ 粗体、斜体、删除线被转换为 Markdown
- ✅ 列表被正确解析

---

### 测试 3：图片消息

### 测试 8：降级机制

**目的**：验证新转换器失败时的自动降级

**步骤**：

1. 临时禁用新转换器（修改配置）：
   ```json
   {
     "channels": {
       "feishu": {
         "messageConverter": {
           "useNewConverters": false
         }
       }
     }
   }
   ```
2. 重启服务：`openclaw restart`
3. 发送消息测试

**预期结果**：

- 日志显示 "using legacy parser"
- 机器人仍然正常工作

**验证点**：

- ✅ 日志显示使用旧解析器
- ✅ 基础功能正常

**恢复**：
删除配置中的 `messageConverter` 部分，重启服务

## ⚠️ 常见问题

### 问题 1：日志显示 "using legacy parser"

**原因**：配置中禁用了新转换器

**解决**：

1. 检查 `~/.openclaw/openclaw.json`
2. 确认没有 `"useNewConverters": false`
3. 重启服务

### 问题 2：合并转发显示 "[Merged Forward]"

**原因**：API 调用失败或权限不足

**解决**：

1. 检查日志中的错误信息
2. 确认飞书机器人有 `im:message` 权限
3. 检查网络连接

### 问题 3：富文本解析失败

**原因**：富文本格式不符合预期

**解决**：

1. 查看日志中的错误信息
2. 尝试简单的富文本内容
3. 如果持续失败，会自动降级到旧解析器
